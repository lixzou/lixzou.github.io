# Bundled fonts

These files are self-hosted so the site does not depend on Google Fonts at runtime
(which is often slow or unreachable from mainland China).

| File | Family | Source |
| --- | --- | --- |
| `inter-latin.woff2` | Inter (variable, wght 400–700, latin subset) | https://fonts.google.com/specimen/Inter |
| `source-serif-4-latin.woff2` | Source Serif 4 (variable, wght 400–700, latin subset) | https://fonts.google.com/specimen/Source+Serif+4 |
| `source-serif-4-italic-latin.woff2` | Source Serif 4 Italic (variable, wght 400–700, latin subset) | https://fonts.google.com/specimen/Source+Serif+4 |

Both families are licensed under the SIL Open Font License 1.1:

- Inter: https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
- Source Serif 4: https://github.com/google/fonts/blob/main/ofl/sourceserif4/OFL.txt
